# История разработки nebo с Claude Code

Проект написан в диалоге с Claude Code. Здесь — тот диалог, чтобы в форке было видно не только
что сделано, но и почему: какие варианты отбросили, что не заработало, какие решения принял человек.

- `sessions/ГГГГ-ММ-ДД.md` — по дням: реплики пользователя, ответы агента, короткие пометки о вызовах
  инструментов (`Bash` + описание команды, `Edit` + файл и т. п.), ответы на вопросы с вариантами.
  Когда контекст переполнялся, Claude Code сжимал его в сводку — сводки тоже здесь (свёрнуты).
- `memory/` — память агента между сессиями (сейчас одно правило: действия с железом — первым списком).
- Актуальная памятка — [../CLAUDE.md](../CLAUDE.md); здесь — история, она может противоречить коду.

Чего здесь нет: вывода команд, картинок (скриншоты экрана и панели Cloudflare), «мыслей» агента.
Адреса, домены, точные координаты, почта, токены заменены заглушками (`<адрес малинки>`, `<домен>`,
`<почта>`…), координаты дома — на центр Лимассола (34.68, 33.04).

Выгружено скриптом [tools/export_context.py](../tools/export_context.py) из записей сессий Claude Code
(`~/.claude/projects/…/*.jsonl`); список замен — локальный файл, в репозиторий не входит.
Ранняя часть (до первого кода) шла в обычном чате claude.ai, её итог — первая версия CLAUDE.md.
