Чтобы человеку с Android пустило на сайт, ему нужен доступ в Cloudflare Access. Сейчас вход открыт только для твоей почты.
1. В панели Cloudflare открой Zero Trust → Access → Applications → nebo → Policies.
2. В правило с твоей почтой (Include → Emails) добавь его адрес.
3. Пусть откроет https://nebo.<домен>/ar, введёт код из письма, нажмёт «Начать» и разрешит камеру и геопозицию.
4. После проверки удали его адрес из правила, если доступ ему больше не нужен.

Дай ему это по ссылке, а не по домашнему Wi-Fi: по http://<адрес малинки>:8080 браузер не даёт сайту камеру и компас, а значит, AR не заработает.

**Claude** · 07:37

Нашёл одно стоящее дополнение: на Wikimedia Commons у многих бортов есть своя категория по регистрации. Это фото именно этого самолёта, а не типа. Условия те же, что у фото судов: Commons мы уже используем. Остальные источники либо закрыты, либо почти ничего не добавляют. Вертолёты есть во всех этих базах наравне с самолётами, для них всё то же самое.

| Источник | Условия | Что даёт нам |
|---|---|---|
| **planespotters.net** (уже стоит) | Открытый API с правилами: автор рядом с фото, ссылка, описание храним не дольше суток | Основной источник, лучшее покрытие |
| **Commons, категория «регистрация (aircraft)»** | Свободные лицензии CC, нужны автор и лицензия; общие правила Wikimedia, как для судов | Проверил 10 бортов из приёма, своя категория с фото у 4: 4X-IHE, 4X-EKA (38 фото), A6-EFT, G-NEWG. Стоит добавить следующим шагом после planespotters, раньше фото типа |
| **airport-data.com** | API открыт, но условий для фото нет. На сайте только «All rights reserved» и «только для просмотра и получения информации», фото принадлежат фотографам | Фото нашлось у 2 бортов из 8, и оба уже есть на planespotters. Превью маленькие, около 200 px. Брать не стоит: прав никто не даёт, а нового почти нет |
| **Openverse** (поиск по свободным фото, в том числе с Flickr) | Запрещено выкачивать каталог; лицензию каждого фото проверяем сами; за коммерческое использование могут брать плату | Нашлось 2 фото из 5 запросов: одно — дубль с Commons, второе — Flickr с некоммерческой лицензией и на другой борт той же Wizz Air. Отвечает медленно, один запрос завис. Не стоит |
| **Flickr API** | Нужен ключ; не больше 30 фото на страницу; обязательная надпись «uses the Flickr API but is not endorsed…»; лицензию каждого фото соблюдать самим | Часть фото там под «все права защищены», часть под некоммерческими лицензиями. Свободные с подходящей лицензией и так часто лежат на Commons. Морока больше, чем толку |
| **JetPhotos** (принадлежит Flightradar24) | Официального API нет; права у фотографов | Нельзя, как и MarineTraffic для судов |
| **Airliners.net** | API нет | Нельзя |
