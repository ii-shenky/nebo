# Локальный источник для Nebo Deck

ТЗ для агента, который пишет плагин Nebo Deck. Серверная часть уже готова (`tools/demo/serve.py`
в проекте nebo), плагину нужен только третий источник рядом с adsb.lol и adsb.fi.

## Что отдаёт сервер

Сервер nebo (Mac с RTL-SDR, `dump1090-fa`) слушает порт 8080 и повторяет API adsb.lol:

    GET http://<host>:8080/v2/lat/{lat}/lon/{lon}/dist/{nm}
    GET http://<host>:8080/v2/point/{lat}/{lon}/{nm}        (та же выдача)

Ответ — как у `https://api.adsb.lol/v2/lat/…/lon/…/dist/…`:

    {"ac": [...], "msg": "No error", "now": 1792411992300, "total": 3, "ctime": 1792411992300, "ptime": 0}

- `ac` — записи readsb (`hex`, `flight`, `lat`, `lon`, `alt_baro`, `gs`, `track`, `baro_rate`,
  `squawk`, `category`, `seen`, `seen_pos`, `rssi`…) в круге радиусом `nm` морских миль,
  отсортированы по расстоянию; у каждой добавлены `dst` (мор. мили) и `dir` (азимут от точки).
- `now` в миллисекундах, как у adsb.lol.
- Чего нет: `r`, `t`, `desc`, `dbFlags` — у локального приёмника нет базы бортов.
  У плагина уже есть дозапрос личности (identity backfill) у другого источника по той же
  области — он закроет типы и регистрации.
- Ошибки: `503`, если `dump1090` не обновлял данные больше 60 с (приёмник выключен) или файл
  ещё не записан. Любой не-2xx плагин уже считает отказом источника → backoff и переход на
  следующий источник, то есть при выключенном донгле Stream Deck сам вернётся к adsb.lol.
- CORS: `Access-Control-Allow-Origin: *`. Ключ и User-Agent не нужны.

Адрес Mac в локальной сети печатается при старте сервера (строка «как adsb.lol: …»).
Если плагин на том же Mac — `http://127.0.0.1:8080`.

## Что нужно в плагине

1. `SourceId` добавить `"local"`; в конфиге — `localUrl` (базовый адрес, по умолчанию
   `http://127.0.0.1:8080`); эндпоинт `${localUrl}/v2/lat/${lat}/lon/${lon}/dist/${nm}`.
2. Разбор ответа тот же, что для adsb.lol (`body.ac`).
3. Порядок источников: `local` только когда выбран явно; adsb.lol и adsb.fi остаются
   запасными после него (сейчас `normalizeConfig` добавляет все `SOURCE_IDS` как fallback —
   для `local` этого делать не надо, иначе у всех без сервера будет вечный backoff).
4. В backfill личности `local` как источник не использовать — у него нет типов.
5. Настройки: пункт «Локальный приёмник» в выборе основного источника и поле адреса —
   в окне Settings и в панели Stream Deck; строки в 7 локалях.
6. Интервал опроса можно опускать до минимума (10 с): локальный сервер лимитов не имеет.

## Как проверить

На Mac с донглом: `python3 tools/demo/serve.py --lat 34.68 --lon 33.04 --ppm 31`
(порт 8080), затем `curl 'http://127.0.0.1:8080/v2/lat/34.68/lon/33.04/dist/40'`.
Страница http://localhost:8080/ показывает те же борты на карте.
