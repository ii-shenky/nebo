# nebo — что летит над головой

*A Raspberry Pi desk display for the aircraft (and ships) around you: own ADS-B/AIS receiver,
3.2" touchscreen, web page and phone AR. Written and maintained with Claude Code; docs are in Russian.*

Настольное табло на Raspberry Pi 4: какие самолёты сейчас рядом — рейс, откуда → куда, высота,
расстояние, фото борта. Данные — со своей антенны (RTL-SDR) или из интернета (adsb.lol).

## Что умеет

- **Табло 3,2"** (320×240, сенсорный): карточка борта с фото и мини-картой → радар → список.
  Кнопки и свайпы, тап по фото — QR-код со ссылкой на снимок.
- **Свой приёмник ADS-B** (readsb + донгл RTL-SDR) — или adsb.lol, если антенны нет.
- **Веб-страница**: все принятые борта на карте, таблица, карточка с маршрутом, фото, графиком высоты,
  страной регистрации; контур дальности приёма; маршруты всех бортов за 2 часа с архивом.
- **AR для телефона** (`/ar`): наводишь камеру на небо — подписи самолётов, радар, стрелки «куда довернуть».
  Нужен HTTPS (например, Cloudflare Tunnel).
- **Суда (AIS)** тем же донглом: страница `/ships` переключает приёмник на 162 МГц и обратно.
- **Навигация на карте**: радиомаяки и аэродромы (OurAirports), путевые точки и трассы из AIP
  (сборщик для района Никосии; данные AIP в репозитории не лежат — см. ниже).
- **Фото**: planespotters.net → снимок борта на Wikimedia Commons → фото такого же типа из Википедии
  (с пометкой «не этот борт») → силуэт.

## Без антенны

Свисток RTL-SDR не обязателен: без него nebo берёт самолёты из открытого API [adsb.lol](https://adsb.lol)
(данные ODbL, ключ не нужен). Это режим по умолчанию в [config.example.toml](config.example.toml):

```toml
[source]
type = "adsblol"   # свой приёмник — "readsb"
interval = 60      # adsb.lol банит за частые запросы, чаще раза в минуту не стоит
```

Работает всё, кроме того, что требует своего приёма: табло, страница самолётов, маршруты, фото,
AR (позиции между опросами досчитываются по курсу и скорости). Самолёты — в круге `radius_km` (80 км)
вокруг дома. Нет: статистики приёма и контура дальности (их даёт readsb) и судов — их nebo принимает
только сам (AIS-catcher). Появится свисток — поставить readsb и сменить `type` на `"readsb"`.

## Железо

- Raspberry Pi 4, Raspberry Pi OS Lite 64-bit (Debian 13).
- Экран «3.2inch RPi Display» (ILI9341 + XPT2046, клон Waveshare 3.2" B) — работает на штатных оверлеях.
- Необязательно: донгл RTL-SDR (RTL2832U + R820T) и антенна на 1090 МГц — см. «Без антенны».

Подробности подключения экрана, кнопок, сборки readsb и AIS-catcher — в [CLAUDE.md](CLAUDE.md).

## Установка (кратко)

1. На малинке: `sudo apt install python3-pil python3-numpy python3-qrcode fonts-dejavu-core fonts-dejavu-extra
   fonts-roboto-unhinted rsync`, оверлеи экрана в `/boot/firmware/config.txt` (см. CLAUDE.md).
2. Со своего компьютера: `NEBO_HOST=<адрес малинки> ./deploy.sh` — скопирует код, поставит `nebo.service`.
3. Поправить `/etc/nebo/config.toml` (координаты дома, источник данных, контакт для planespotters) —
   пример в [config.example.toml](config.example.toml).
4. Свой приёмник: собрать readsb (и, если нужны суда, AIS-catcher) из исходников — команды в CLAUDE.md;
   `deploy.sh` поставит юниты из `deploy/`. Координаты в `deploy/*.default` — пример, поставить свои.

**Безопасность.** Веб-страница показывает координаты дома и умеет переключать донгл — наружу только
за авторизацией (у нас — Cloudflare Access). AIS-catcher по умолчанию отправляет приём в сообщество
aiscatcher.org — в наших юнитах `-X off`.

## Данные и лицензии

Код — [MIT](LICENSE). Данные в `nebo/data/` — от третьих сторон, источники и условия — в
[nebo/data/README.md](nebo/data/README.md). AIP Кипра распространять нельзя: путевые точки собираются
`tools/build_aip.py` из своей копии AIP.
