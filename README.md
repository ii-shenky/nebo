# nebo — что летит над головой

*A Raspberry Pi desk display for the aircraft (and ships) around you: own ADS-B/AIS receiver,
3.2" touchscreen, web page and phone AR. Written and maintained with Claude Code; docs are in Russian.*

Настольное табло на Raspberry Pi 4: какие самолёты сейчас рядом — рейс, откуда → куда, высота,
расстояние, фото борта. Данные — со своей антенны (RTL-SDR) или из интернета (adsb.lol).

## Что умеет

- **Табло 3,2"** (320×240, сенсорный): карточка борта с фото и мини-картой → радар → список.
  Кнопки и свайпы, тап по фото — QR-код со ссылкой на снимок.
- **Свой приёмник ADS-B** (readsb + донгл RTL-SDR) — или adsb.lol, если антенны нет.
- **Веб-страница**: все принятые борта на карте, таблица, карточка с маршрутом, фото, графиком высоты,
  страной регистрации; контур дальности приёма; маршруты всех бортов за 2 часа с архивом.
- **AR для телефона** (`/ar`): наводишь камеру на небо — подписи самолётов, радар, стрелки «куда довернуть».
  Нужен HTTPS (например, Cloudflare Tunnel).
- **Суда (AIS)** тем же донглом: страница `/ships` переключает приёмник на 162 МГц и обратно.
- **Навигация на карте**: радиомаяки и аэродромы (OurAirports), путевые точки и трассы из AIP
  (сборщик для района Никосии; данные AIP в репозитории не лежат — см. ниже).
- **Фото**: planespotters.net → снимок борта на Wikimedia Commons → фото такого же типа из Википедии
  (с пометкой «не этот борт») → силуэт.

## Что вам понадобится

Ничего, кроме компьютера с интернетом. Всё остальное — по желанию:

| Есть у вас | Что получится | Как запустить |
|---|---|---|
| только компьютер (Linux, macOS, Docker) | веб-страница и AR, самолёты из интернета ([adsb.lol](https://adsb.lol)) | [Docker](#docker) или [Python](#python-без-docker) |
| + Raspberry Pi с экраном 3,2" | ещё и настольное табло с кнопками и свайпами | [На малинке](#на-малинке) |
| + свисток RTL-SDR и антенна 1090 МГц | свой приём: всё, что слышит антенна (у нас — до 380 км), контур дальности, статистика | [Свой приёмник](#свой-приёмник) |
| + тот же свисток | суда (AIS) — по очереди с самолётами, страница сама переключает | [Свой приёмник](#свой-приёмник) |

Без свистка самолёты приходят из открытого API adsb.lol раз в минуту в круге 80 км от дома (между опросами
позиции досчитываются по курсу и скорости). Нет только того, что требует своего приёма: контура дальности,
статистики приёма и судов. Без экрана (`[display] screen = false` — или экран просто не найден) nebo
работает как веб-страница.

> **Лень читать дальше?** Откройте этот репозиторий в Claude Code (или в другом агенте) и скажите:
> «поставь мне nebo — у меня есть вот это». Агент прочитает [CLAUDE.md](CLAUDE.md), где записано всё,
> на что мы наступили, и сделает остальное. Проект и так больше для агентов, чем для людей: людям
> достаются только кнопки, свайпы и «готово, нажал».

## Docker

```sh
docker build -t nebo .
docker run -d -p 127.0.0.1:8080:8080 -v nebo-state:/var/lib/nebo nebo
```

Откройте http://localhost:8080. По умолчанию — центр Лимассола; свой дом и контакт для фото
planespotters — в своём конфиге: `-v $PWD/config.toml:/etc/nebo/config.toml:ro`
(пример — [config.example.toml](config.example.toml), `screen = false`). Порт открыт только для этого
компьютера: страница без авторизации, а с вашим конфигом показывает координаты дома. Нужен доступ из сети —
`-p 8080:8080`, но наружу (в интернет) — только за авторизацией (см. «Безопасность» ниже).

## Python без Docker

```sh
python3 -m venv .venv                     # Python 3.11+
.venv/bin/pip install pillow qrcode
cp config.example.toml config.toml        # координаты дома, [display] screen = false
.venv/bin/python -m nebo --config config.toml   # → http://localhost:8080
```

Состояние (маршруты, кеши) — в `~/.cache/nebo` или в `$STATE_DIRECTORY`.

## На малинке

- Raspberry Pi 4, Raspberry Pi OS Lite 64-bit (Debian 13).
- Экран «3.2inch RPi Display» (ILI9341 + XPT2046, клон Waveshare 3.2" B) — работает на штатных оверлеях.

1. На малинке: `sudo apt install python3-pil python3-numpy python3-qrcode fonts-dejavu-core fonts-dejavu-extra
   fonts-roboto-unhinted rsync`, оверлеи экрана в `/boot/firmware/config.txt` (см. CLAUDE.md).
2. Со своего компьютера: `NEBO_HOST=<адрес малинки> ./deploy.sh` — скопирует код в `~/nebo`, поставит `nebo.service`
   от того пользователя, под которым вы заходите по ssh (ему нужны группы `video` и `input` — для экрана и кнопок).
3. Поправить `/etc/nebo/config.toml` (координаты дома, источник данных, контакт для planespotters) —
   пример в [config.example.toml](config.example.toml).

## Свой приёмник

Донгл RTL-SDR (RTL2832U + R820T, «свисток» за $20–40) и антенна на 1090 МГц. Собрать readsb (и, если нужны
суда, AIS-catcher) из исходников — команды и грабли в [CLAUDE.md](CLAUDE.md); `deploy.sh` поставит юниты
из `deploy/` (координаты в `deploy/*.default` — пример, поставить свои). В конфиге:

```toml
[source]
type = "readsb"
path = "/run/readsb/aircraft.json"
interval = 2
```

**Безопасность.** Веб-страница показывает координаты дома и умеет переключать донгл — наружу только
за авторизацией (у нас — Cloudflare Access). AIS-catcher по умолчанию отправляет приём в сообщество
aiscatcher.org — в наших юнитах `-X off`.
